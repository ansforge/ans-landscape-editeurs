# Exemples d'intégration

Ce dossier accueillera les exemples de code par langage (`java/`, `javascript/`, `python/`, `curl/`).

Aucun exemple n'est publié pour l'instant. Pour en ajouter un :

1. Créez le fichier dans le dossier du langage, avec un nom qui commence par l'id du service (par exemple `curl/prosante-connect-decouverte.sh`).
2. Ajoutez le langage dans le champ `examples` du service dans `data/services.yml`.
3. N'y mettez aucun secret ni identifiant réel : uniquement des valeurs de test documentées par le propriétaire du service.
